## 5. Analisa Kerusakan

| Faktor Kerusakan | Uraian |
|---|---|
| Lonjakan arus besar (High Current/Ampere Load) | Sakelar mengalirkan arus listrik utama dari baterai ke starter. Masalah pada sistem starter atau korsleting dapat menyebabkan sakelar menahan beban arus melebihi kapasitas, menimbulkan panas berlebih, dan melelehkan komponen internal. |
| Arcing/percikan api pada kontak | Ketika sakelar diaktifkan atau dinonaktifkan saat mesin hidup atau dalam kondisi beban tinggi, dapat terjadi percikan api di dalam sakelar. Arcing berulang mengikis kontak tembaga dan dapat menyebabkan *soft weld*, kontak menempel, atau hangus sehingga sakelar tidak dapat digunakan. |
| Kegagalan koneksi | Parts sudah pernah diperbaiki, tetapi tetap tidak dapat terkoneksi dengan wiring pengoperasian fitur pemadatan dan brake system. |
| Dampak operasional | Sistem kelistrikan yang berkaitan dengan fungsi pemadatan dan pengereman tidak dapat beroperasi sebagaimana mestinya. |
