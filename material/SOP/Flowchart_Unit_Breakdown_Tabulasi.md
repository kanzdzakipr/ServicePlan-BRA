# Flowchart Prosedur Penerimaan Service Dump Truck / Alat Berat

## 1. Identitas Dokumen

| Keterangan | Isi |
|---|---|
| Judul | Flow Chart Prosedur Penerimaan Service Dump Truck / Alat Berat |
| Proses utama | Penanganan unit break down sampai unit ready |
| Titik keputusan | Butuh penggantian spare part |
| Dokumen utama | Job Order, SPB/SPPU, BAPB, BHW-IN, BKTBI, BHW-OUT, Lembar Aktivitas Mekanik, dan BA Unit Ready |
| Dibuat oleh | Dean Martin - Admin |
| Diperiksa oleh | Dany Agung - Head of Equipment |
| Diketahui oleh | Widya Apriani - Asset Manager |

## 2. Alur Proses Utama

| No. | Tahap | Keputusan/Kondisi | Hasil atau Tahap Berikutnya |
|---:|---|---|---|
| 1 | Start | - | Proses dimulai. |
| 2 | Unit break down | Unit dilaporkan oleh Driver. | Admin Yard menerima laporan HM/KM dan seluruh kerusakan. |
| 3 | Buat Job Order dan registrasi unit down | - | Job Order dilengkapi, ditandatangani, dan unit diregistrasi ke Link Laporan Bdown. |
| 4 | Butuh penggantian spare part? | **Ya** | Buat Surat Permintaan Barang/Part Urgent, kemudian realisasi SPB/SPPU. |
| 5 | Butuh penggantian spare part? | **Tidak** | Langsung ke proses pengerjaan unit break down. |
| 6 | Part masuk di gudang | Berlaku apabila membutuhkan spare part. | Penerimaan dibuktikan dengan BAPB dan dicatat pada BHW-IN. |
| 7 | Pemakaian part sesuai SPPU dan JO | Part tersedia dan diterima gudang. | Pengeluaran dibuktikan dengan BKTBI dan dicatat pada BHW-OUT. |
| 8 | Proses pengerjaan unit break down | Unit dikerjakan Mekanik dan Helper. | Aktivitas repair dan maintenance dicatat. |
| 9 | Pembuatan BA Serah Terima Unit Ready | Pekerjaan telah selesai. | Unit ready dibuktikan dengan berita acara dan foto part baru terpasang. |
| 10 | End | - | Proses selesai. |

## 3. Tabulasi PIC, Dokumen, dan Persyaratan

| Tahap | PIC/Dokumen | Penanggung Jawab | Informasi, Bukti, atau Tanda Tangan |
|---|---|---|---|
| Pelaporan unit break down | Laporan awal | Driver dan Admin Yard | Driver menginformasikan KM/HM dan semua kerusakan kepada Admin Yard. |
| Job Order dan registrasi | JO | Admin Yard | Berisi nama Driver, Operator, HM/KM, waktu, nomor lambung, jenis kerusakan, dan informasi lain. Ditandatangani Mekanik, Driver, dan CEM. |
| Job Order dan registrasi | Entry laporan | Admin Yard | Unit down diregistrasi ke Link Laporan Bdown. |
| Permintaan barang/part | SPB | Admin Gudang | Permintaan barang/part disertai foto part rusak yang diminta. |
| Permintaan barang/part | SPPU | Admin Yard | Permintaan dari Mekanik kepada Bagian Logistik. |
| Permintaan barang/part | Foto kerusakan | Mekanik yang bersangkutan | Dokumen ditandatangani Mekanik, Admin, Logistik, CEM, HE, dan Manager Asset. |
| Part masuk gudang | BAPB | Admin Gudang | Part/barang masuk dibuktikan dengan Berita Acara Penerimaan Barang. |
| Part masuk gudang | BHW-IN | Admin Yard | BAPB dicatat ke dalam BHW-IN. Ditandatangani Vendor, Admin Gudang, dan Logistik. |
| Pemakaian part | BKTBI | Admin Gudang | Pemakaian service dibuktikan dengan Bukti Kirim/Terima Barang Intern. |
| Pemakaian part | BHW-OUT | Admin Yard | Ditandatangani Admin Gudang, Mekanik, dan CEM; dicatat ke BHW-OUT serta part difoto. |
| Proses repair | Repair | Mekanik | Unit down dikerjakan Mekanik dan Helper. |
| Proses repair | Catatan aktivitas | Admin Yard | Aktivitas dicatat pada Lembar Aktivitas Mekanik dan ditandatangani Mekanik, Helper, Admin, Logistik, dan CEM. |
| Unit ready | BA Unit Ready | Admin Yard | Berita Acara Serah Terima Unit Ready. |
| Unit ready | Foto part | Mekanik | Dilampirkan foto-foto part baru yang telah terpasang. Ditandatangani Driver, CEM, dan HE. |

## 4. Alur Bercabang

| Kondisi | Jalur Proses |
|---|---|
| Butuh penggantian spare part | SPB/SPPU -> Realisasi SPB/SPPU -> Part masuk gudang -> Pemakaian part sesuai SPPU dan JO -> Proses repair -> BA Unit Ready |
| Tidak butuh penggantian spare part | Langsung ke proses repair -> BA Unit Ready |

## 5. Dokumen yang Digunakan

| Singkatan/Nama | Fungsi pada Flowchart |
|---|---|
| JO / Job Order | Mencatat identitas unit, Driver/Operator, HM/KM, waktu, dan kerusakan. |
| SPB | Surat permintaan barang/part yang ditangani Admin Gudang. |
| SPPU | Surat permintaan part urgent yang ditangani Admin Yard. |
| BAPB | Bukti penerimaan barang yang masuk ke gudang. |
| BHW-IN | Buku/catatan barang masuk Warehouse. |
| BKTBI | Bukti Kirim/Terima Barang Intern untuk penggunaan part. |
| BHW-OUT | Buku/catatan barang keluar Warehouse. |
| Lembar Aktivitas Mekanik | Mencatat aktivitas repair dan maintenance. |
| BA Unit Ready | Bukti serah terima bahwa unit telah siap. |

## 6. Catatan Transkripsi

- Istilah `Bdown`, `CEM`, `HE`, `ybs`, dan nama dokumen dipertahankan mengikuti sumber.
- Dokumen sumber tidak menjelaskan kepanjangan `CEM`; kepanjangan tersebut tidak ditambahkan.
- Cabang **T** pada flowchart berarti tidak membutuhkan spare part dan langsung menuju proses pengerjaan unit.
- Cabang **Y** berarti membutuhkan penggantian spare part.
